# 📐 そらほの卓記録：Notion設計メモ

ユーザーとの相談で確定した設計です。新しいセッションでは、このメモの通りに Notion へ作成してください。
同じフォルダの `卓報告テンプレート.md`、`卓報告一覧.csv`、`README.md` は、相談前に作った旧案です。**このメモを優先してください。**

## 🙏 進め方のルール（ユーザーからの依頼）

- **勝手に作り始めないこと。** 何が必要かを確認し、了承を得てから作成する
- 公開ページなので、**わかりやすくシンプルな作り**にする

## 🏠 全体構成

```
🎲 そらほの卓記録（トップページ・Web公開）
 ├─ 🎲 卓報告（データベース）
 └─ 📚 シナリオ一覧（データベース）
```

- 公開はトップページ1つにまとめ、2つのデータベースはその中に置く
- 「Webで公開」の設定はユーザーが Notion の画面で行う。作成後に手順を案内する

## 📚 シナリオ一覧（データベース）

| プロパティ | 種類 | 備考 |
| --- | --- | --- |
| シナリオ名 | タイトル | |
| ふりがな | テキスト | 50音順に並べるために使う（Notionは漢字を読みの順に並べられないため） |
| システム | セレクト | 選択肢：CoC6版 / CoC7版 / エモクロア |
| 所持 | チェックボックス | |
| PL通過 | チェックボックス | PLとして遊んだもの |
| KP/GM済み | チェックボックス | KP/GMとして回したもの（PL通過とは別に管理する） |
| BOOTH | URL | 入手先 |
| 卓報告 | リレーション | 🎲 卓報告とつなぐ（双方向） |
| 遊んだHO | ロールアップ | 卓報告の「自分のHO」をそのまま表示する |

**ビュー（タブ）**：システムごとにタブを作る
- 「CoC6版」「CoC7版」「エモクロア」の3タブ（表形式）
- それぞれ システム＝そのシステム で絞り込み、**ふりがなの昇順（50音順）** で並べる
- 表示列：シナリオ名 / 所持 / PL通過 / KP/GM済み / 遊んだHO / BOOTH
  - ふりがなは並べ替えに使うだけなので、表示しなくてよい

**PL通過について**：卓報告とつないでも、チェックは自動では付かない。手動で付ける（シンプルさを優先した。ユーザーに説明済み）

## 🎲 卓報告（データベース）

| プロパティ | 種類 | 備考 |
| --- | --- | --- |
| タイトル | タイトル | 基本はシナリオ名 |
| シナリオ | リレーション | 📚 シナリオ一覧とつなぐ |
| 開催日 | 日付 | |
| システム | セレクト | CoC6版 / CoC7版 / エモクロア |
| KP/GM | テキスト | |
| 自分のHO | テキスト | 例：「HO1：〇〇」。HOがない卓は空欄 |

**ビュー**：ギャラリー（カード表示）
- カードの画像はページのカバー（ココフォリアの部屋画像）を使う
- 開催日の新しい順に並べる
- カードに出す項目：シナリオ / 開催日 / システム / 自分のHO

**ページ本文のテンプレート**（データベースのテンプレートとして登録する）

```
[カバー画像：ココフォリアの部屋画像 ← ユーザーが自分でアップロードする]

## 👥 参加者
| PL名 | 探索者名 | HO |
| --- | --- | --- |
|  |  | HO1：〇〇 |

## 💬 一言コメント
（エンディング名・生還情報など、自由に書く欄。ユーザー1人分）

▶ ⚠️ ネタバレ感想（トグル。クリックした人だけ読める）
   （感想）
```

- 参加者には PL名と探索者名の両方を載せる（ユーザーの了承済み）
- HO は「HO1：〇〇」の書き方。HOがない卓では空欄にする

## 🔗 X・mixi2での共有

- 公開ページのURLを貼って共有する。カバー画像がリンクのプレビュー画像になることを期待している
- **プレビュー画像が実際に出るかは未確認。** 最初の1件ができたら、XとMixi2に試しに貼って、ユーザーと一緒に確認する

## 📝 既存のシナリオ一覧の取り込み

- ユーザーの手元にシナリオの一覧がある。ただし、ふりがなは付いていない
- 進め方の案：
  1. ユーザーが一覧を貼り付ける（シナリオ名、システム、所持・通過などの状態）
  2. Claude が読みを考えてふりがなを付け、**登録する前に一覧にしてユーザーに確認してもらう**（シナリオ名の読みは独特なことがあるため）
  3. 了承を得てから、まとめて Notion に登録する
