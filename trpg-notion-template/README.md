# 🎲 TRPG卓報告 Notionテンプレート

Notionをはじめて使う人向けの、TRPGの卓報告（セッションレポート）用ひな形です。

## 📦 入っているもの

| ファイル | 中身 |
| --- | --- |
| `卓報告テンプレート.md` | 卓報告1回分のページ（参加者、あらすじ、ダイス記録、感想など） |
| `卓報告一覧.csv` | 卓報告をまとめる一覧表（データベース）のもと |

## 🪜 Notionへの取り込み方（はじめての人向け）

### 1. Notionのアカウントを作る
[notion.com](https://www.notion.com/) で無料アカウントを作ります（個人利用なら無料プランで十分です）。

### 2. 一覧表（データベース）を取り込む
1. 左サイドバーの **「設定」→「インポート」** を開きます（見当たらない場合は、サイドバーの「インポート」）
2. **「CSV」** を選んで `卓報告一覧.csv` を読み込みます
3. 表形式のページ「卓報告一覧」ができます。1行が卓報告1回分です

### 3. 各列の種類を整える（おすすめ）
列名をクリックすると、列の種類を変えられます。

| 列 | おすすめの種類 |
| --- | --- |
| 開催日 | 日付 |
| システム | セレクト |
| 結果 | セレクト（全生還 / ロストあり / 継続 など） |
| ステータス | ステータス（予定 / 報告書き中 / 報告済み） |
| 参加PL・タグ | マルチセレクト |

### 4. 報告テンプレートを登録する
1. 一覧表の右上にある **「新規」の横の ▼** →「**＋新規テンプレート**」を押します
2. テンプレート名を「卓報告」にします
3. `卓報告テンプレート.md` の中身をすべてコピーして、テンプレートの本文に貼り付けます
   （Notionは貼り付けた Markdown を自動で見出しや表に変換してくれます）
4. 以後は ▼ →「卓報告」を選ぶだけで、ひな形入りのページが作れます

### 5. 仕上げのひと工夫 ✨
- **ネタバレ対策**：あらすじを選び、`/トグル` と入力してトグル（折りたたみ）に入れる
- **表示を変える**：一覧表の「＋ビューを追加」から **ギャラリー**（カード表示）や **カレンダー**（開催日で並べる）を追加する
- **カバー画像**：シナリオのイメージ画像や立ち絵をページのカバーに設定する

## 🤖 Claudeと組み合わせると

Claudeアプリの設定でNotionコネクタをつなぐと、次のような頼み方ができます。

- 「このセッションログを読んで、卓報告一覧に新しい報告を作って」
- 「今月の卓報告を読んで、名台詞だけ集めて」
- 「PC〇〇が出た卓報告をまとめて、キャラの歩みを年表にして」
